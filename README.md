# 📚 Просмотр курсов и тестов (Cources Parser)

Веб-приложение для просмотра учебных курсов и правильных ответов на тесты с личного кабинета студента. Работает через локальный Node.js прокси-сервер, который решает проблемы CORS и автоматически управляет сессионными куки.

## 🚀 Быстрый старт (с нуля)

Если ты только что скачал проект, выполни следующие шаги.

### Шаг 1. Установи Node.js

Скачай и установи [Node.js (LTS версию)](https://nodejs.org/ru). 
Во время установки оставь все настройки по умолчанию.

Проверь установку в терминале:
node -v
npm -v
Должны появиться версии (например, v20.11.0 и 10.2.4).

Шаг 2. Распакуй проект
Распакуй архив в удобную папку.
⚠️ Важно: путь к папке не должен содержать кириллицы и пробелов (например, C:\projects\courses-parser — хорошо, C:\Мои документы\курсы — плохо).

Шаг 3. Установи зависимости
Открой терминал в папке проекта (в VS Code: Терминал → Новый терминал или через cmd в адресной строке Проводника) и выполни:

bash
npm install
Эта команда прочитает package.json и скачает нужные пакеты (express, axios, cors) в папку node_modules.

⚠️ Папку node_modules не нужно коммитить в Git и нельзя удалять после установки.

Шаг 4. Запусти сервер
bash
node server.js
В терминале появится:

text
✅ Сервер запущен: http://localhost:3000
⚠️ Терминал должен оставаться открытым. Если закроешь — сервер остановится.

Шаг 5. Открой в браузере
Перейди по адресу: http://localhost:3000

⚠️ Не открывай index.html двойным кликом! Он должен открываться только через Node.js сервер, иначе запросы к API упадут с CORS-ошибкой.

Шаг 6. Войди в систему
Введи логин и пароль от ЛК. После входа список курсов загрузится автоматически. В терминале, где запущен сервер, будет виден пошаговый лог:

🔐 POST /api/login — попытка входа

📚 GET /api/courses — запрос курсов

📖 GET /api/course/:id — запрос деталей конкретного курса

Если увидишь ошибку {"error":"Не авторизован"} — смотри раздел Проблемы и решения.

🛠 Как это работает
text
Браузер → http://localhost:3000 → Node.js (server.js) → https://j.zifra42.ru
Node.js сервер хранит PHPSESSID после логина в памяти.

Браузер общается только с localhost:3000 — CORS не мешает.

Сервер подставляет куки в каждый запрос к реальному API.

Ответы возвращаются в браузер в чистом виде.

🐛 Проблемы и решения
❌ {"error":"Не авторизован"} при загрузке курсов
Причины и что делать:

Ты не залогинился или логин был давно — перезайди. Сервер хранит куку в памяти и не сохраняет между перезапусками.

Куки потерялись — проверь в терминале строки 🍪 Текущие куки:. Если там {} — сервер не получил Set-Cookie от auth.php. Проверь логин/пароль.

PHP-сессия привязана к User-Agent или IP — залогинься через наш Node-сервер (http://localhost:3000), а не через основной сайт в другой вкладке.

❌ Failed to fetch или CORS-ошибка в браузере
Сервер не запущен. Проверь терминал, там должна быть строка ✅ Сервер запущен.

Открыл index.html напрямую (file://...) — нельзя. Открой http://localhost:3000.

❌ Error: Cannot find module 'express'
Забыл выполнить npm install. Выполни и перезапусти сервер.

❌ EADDRINUSE: address already in use :::3000
Порт 3000 занят (старый сервер не закрылся).

Windows: найди процесс через netstat -ano | findstr :3000, убей через taskkill /PID <номер> /F.

Или просто поменяй const PORT = 3000 на 3001 в server.js.

❌ Структура ответа изменилась
Приложение покажет жёлтый баннер с предупреждением, если сервер поменял формат JSON (например, поле covers стало courses). В этом случае нужно обновить логику парсинга в index.html.

🔒 Безопасность
Логин и пароль не сохраняются ни на сервере, ни в браузере — они уходят напрямую на j.zifra42.ru.

Куки хранятся в оперативной памяти Node.js и сбрасываются при перезапуске сервера.

Все запросы идут через твой локальный сервер — никакие данные не уходят третьим лицам.
